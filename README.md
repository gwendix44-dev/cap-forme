# Cap Forme

Application web installable (PWA) de développement personnel : sport au poids du corps, peau, cheveux, sommeil, alimentation, mémoire et concentration.

- Quiz de 20 questions au premier lancement, qui règle le plan, les cases du jour et les séances.
- Cases à cocher quotidiennes (jour calme ou jour de train), anneaux de progression, séries de jours.
- Séances guidées (mini 5, express 10, standard 20, complète 30 minutes) avec progression automatique.
- Thèmes clair et sombre. Fonctionne hors ligne.
- Toutes les données restent sur l'appareil (localStorage, IndexedDB pour les photos). Aucun compte, aucun serveur.

## Lancer en local

```
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000.

## Publier

GitHub Pages, branche `main`, dossier racine.

Cette appli ne remplace pas un avis médical.
